# Tech Stack & Architecture

The CYBER SPACE CLUB web platform uses a modern, scalable **Next.js App Router** architecture.

---

## 🛠️ Core Technologies

### 1. **Framework: Next.js 14 App Router & React 18**
* **App Router (`app/`)**: Server Components for fast initial page loads and SEO optimization.
* **Server Actions**: Direct server-side data mutations without raw boilerplate API code.
* **TypeScript**: Strict static typing across components, API routes, and database models.

---

### 2. **Database & Auth: Supabase (PostgreSQL & SSR)**
* **PostgreSQL Database**: Scalable relational database for users, events, and certificates.
* **Supabase SSR (`@supabase/ssr`)**: Server-Side session cookie handling.
* **Google OAuth**: One-click Google Sign-In for Admin portal and club members.
* **Row Level Security (RLS)**: Fine-grained security policies on database tables.

---

### 3. **Media Storage: Cloudinary**
* **Cloud Storage**: High-speed photo and video asset hosting.
* **Image Optimization (`next-cloudinary`)**: Automatic WebP compression, image resizing, and responsive thumbnails.

---

### 4. **Security: Cloudflare Turnstile**
* **Bot Protection (`@marsidev/react-turnstile`)**: Smart CAPTCHA challenge protection for forms and registration endpoints.

---

### 5. **Styling: Tailwind CSS**
* **Utility-First CSS**: Rapid responsive UI styling.
* **PostCSS**: Automated CSS processing and optimization.

---

### 6. **Documentation Engine: Fumadocs MDX**
* **Fumadocs (`fumadocs-ui` & `fumadocs-core`)**: Instant client-side search (`Ctrl + K`), dynamic MDX parsing, and responsive documentation layout.
