# Local Setup & Environment

Follow these steps to set up and run the Cyberspace Club web platform on your local machine.

---

## 📋 Prerequisites

* **Node.js**: v18.0.0 or higher
* **npm**: v9.0.0 or higher
* **Git**

---

## 🚀 Installation Steps

### 1. Clone the Repository
```bash
git clone https://github.com/Boeing777-X9/CSC26.git
cd CSC26
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file in the root directory and add your project keys:

```env
# Supabase Configuration
NEXT_PUBLIC_SUPABASE_URL="https://riqlqnqyenolgpqdijml.supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="your-supabase-anon-key"

# Cloudinary Storage
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME="your-cloud-name"
CLOUDINARY_API_KEY="your-api-key"
CLOUDINARY_API_SECRET="your-api-secret"

# Cloudflare Turnstile
NEXT_PUBLIC_TURNSTILE_SITE_KEY="your-site-key"
TURNSTILE_SECRET_KEY="your-secret-key"
```

### 4. Run Development Server
```bash
npm run dev
```

Visit `http://localhost:3000` to view the web application and `http://localhost:3000/docs` to view the live documentation portal!
